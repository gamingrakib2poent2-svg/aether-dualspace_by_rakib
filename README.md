# Aether Space - Dual Space & Virtual Camera Vault (iOS 26 Liquid Glass)

**Aether Space** হলো একটি নেক্সট-জেনারেশন প্রাইভেট ডুয়াল স্পেস এবং ভার্চুয়াল ক্যামেরা অ্যান্ড্রয়েড অ্যাপ্লিকেশন। এটি অ্যাপল iOS 26 ফ্রস্টেড গ্লাস থিম (Liquid Glassmorphism) ডিজাইনে তৈরি।

---

## 🌟 প্রধান ফিচারসমূহ (Core Features)

1. **Dual Space & Cloned Apps:**
   - সম্পূর্ণ আলাদা স্যান্ডবক্স পরিবেশ যেখানে ক্লোনড অ্যাপস (WhatsApp, Telegram, Facebook, Browser ইত্যাদি) চালানো যায়।
   - কুকিজ, ক্যাশে এবং সেশন ডাটা মূল ফোনের স্টোরেজ থেকে সম্পূর্ণ আলাদা থাকে।

2. **Virtual Camera Control (ভার্চুয়াল ক্যামেরা কন্ট্রোল):**
   - **Real Cam Mode:** সাধারণ রিয়েল ক্যামেরা ফিড।
   - **Virtual Feed Mode:** নিজস্ব প্রাইভেট গ্যালারি থেকে যেকোনো ভিডিও বা ছবি সিলেক্ট করে সরাসরি ক্যামেরা ফিড হিসেবে ইনজেক্ট করা যায় (অন্য কোনো অ্যাপ ক্যামেরা দেখতে চাইলে ভার্চুয়াল ভিডিও স্ট্রিম দেখতে পাবে)।
   - **Privacy Shield Mode:** সম্পূর্ণ ব্ল্যাকআউট/ক্যামেরা সেন্সর ব্লক মোড।
   - রেজোলিউশন অ্যাডজাস্টমেন্ট (1080p, 720p) এবং রিয়েলিস্টিক সেন্সর নয়েজ ফিল্টার।

3. **Secure Vault Gallery (নিজস্ব গোপন গ্যালারি):**
   - সাধারণ অ্যান্ড্রয়েড সিস্টেম গ্যালারি (Google Photos বা ফোনের গ্যালারি) থেকে সম্পূর্ণ লুকানো এনক্রিপ্টেড স্টোরেজ।
   - ছবি, ভিডিও এবং অডিও আলাদা ট্যাবে সংরক্ষণ।
   - যেকোনো ভিডিও বা ছবিকে এক ক্লিকে "Set as Virtual Cam Feed" বানানোর ব্যবস্থা।

4. **Integrated Media Player (iOS 26 Glass Player):**
   - **AndroidX Media3 (ExoPlayer)** দিয়ে তৈরি পাওয়ারফুল ভিডিও ও অডিও প্লেয়ার।
   - লিকুইড গ্লাস স্ক্রাবার, দ্রুত ১০ সেকেন্ড স্কিপ, ব্যাকগ্রাউন্ড অডিও প্লেব্যাক এবং ভলিউম কন্ট্রোল।

5. **iOS 26 Liquid Glass Theme:**
   - ফ্রস্টেড গ্লাস (Translucent Frosted Blur) কার্ড এবং বাটন।
   - ডায়নামিক আইল্যান্ড স্ট্যাটাস বার।
   - ফ্লোটিং গ্লাস ডক (Bottom Navigation Bar)।

## 🚀 কীভাবে বিনামূল্যে ২ মিনিটে APK ডাউনলোড করবেন (GitHub Actions)

আপনার কম্পিউটারে ভারী কোনো অ্যান্ড্রয়েড স্টুডিও না থাকলেও GitHub-এর ফ্রি সার্ভার ব্যবহার করে ২ মিনিটে রেডিমেড `.apk` ফাইল পেয়ে যাবেন:

1. [GitHub.com](https://github.com)-এ গিয়ে একটি ফ্রি একাউন্ট খুলুন (বা লগইন করুন)।
2. **New Repository** বাটনে ক্লিক করে যেকোনো নামে একটি প্রাইভেট বা পাবলিক রিপোজিটরি তৈরি করুন (যেমন: `my-dualspace-app`)।
3. এই জিপ ফাইলের ভেতরের সব ফাইল সেখানে আপলোড করুন (বা গিট পুশ করুন)।
4. আপনার রিপোজিটরির **"Actions"** ট্যাবে যান।
5. সেখানে **"Build Android APK"** স্বয়ংক্রিয়ভাবে চালু হয়ে যাবে। মাত্র ২-৩ মিনিটের মধ্যে বিল্ড সম্পন্ন হলে **Artifacts** সেকশনে ক্লিক করলেই **`Aether-DualSpace-Debug-APK`** সরাসরি ডাউনলোড হয়ে যাবে!
6. ফাইলটি ডাউনলোড করে আপনার অ্যান্ড্রয়েড ফোনে ইনস্টল করে নিন।

## 💻 অ্যান্ড্রয়েড স্টুডিও দিয়ে বিল্ড করতে চাইলে (Local Build)

1. **Android Studio** (Hedgehog বা পরবর্তী সংস্করণ) ওপেন করুন।
2. `File > Open` দিয়ে `dualspace_app` ফোল্ডারটি সিলেক্ট করুন।
3. প্রজেক্ট সিঙ্ক শেষ হলে মেনু থেকে `Build > Build Bundle(s) / APK(s) > Build APK(s)` চাপুন।
4. কয়েক সেকেন্ডের মধ্যে আপনার কম্পিউটারে `app-debug.apk` তৈরি হয়ে যাবে।

## 🛠️ টেকনিক্যাল স্পেসিফিকেশন

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (BOM 2024.02.00)
- **Theme:** iOS 26 Glassmorphism / Cupertino styled Material 3
- **Camera Engine:** CameraX 1.3.1 + Virtual Frame Interceptor
- **Media Engine:** AndroidX Media3 (ExoPlayer 1.2.1)
- **Target SDK:** Android 14 (API Level 34)
- **Minimum SDK:** Android 8.0 (API Level 26)
